# 受限终端读取与上下文预算

## 默认最新优先

0.6 将整份历史快照改为三个入口：read_output 读取当前画面的变化，read_screen 显式读取当前快照，read_history 显式读取普通屏幕历史。认领和创建仍只返回元数据，不自动获取终端正文。

普通屏幕默认从当前画面底部的最新内容开始，不从最早未读记录追赶。进入备用屏幕时先观察当前程序的画面，不能先回放之前几百行 Shell 命令。备用屏幕只能说明终端切换了缓冲区，不能据此断定程序一定是 Vim。退出后返回普通屏幕，并标记需要重新同步。

终端仍以服务端 canonical xterm 为唯一内容来源。新增的是传输预算和比较哈希，不是隐藏输出日志；覆盖、清空和滚动淘汰仍会真正缩小可读取内容范围。

## 预算与接口

所有终端工具默认最多 4000 文本字符和 40 行片段。maxChars 可设 128–16000，maxLines 可设 1–100。上限作用于文本及行间换行，按 JavaScript UTF-16 码元计数，JSON 元数据另计；它不是精确模型 Token 数。返回结构固定且有界，不携带冗长会话身份或重复的正文副本。

| 工具 | 默认行为 | 显式继续 |
| --- | --- | --- |
| read_output | 首次受限快照；之后当前画面的变化行 | nextCursor 查看截断画面；resync=true 重同步 |
| read_screen | 当前画面的受限快照和光标 | nextCursor；startRow 指定屏幕内起始行 |
| read_history | 普通屏幕的最近保留内容，向更早方向分页 | nextCursor 作为 cursor |

所有工具都不自动翻页。正常屏幕一页内按自然行序呈现，但选取和下一页方向为“最近 → 更旧”。备用屏幕从光标附近的行开始按屏幕顺序显示，nextCursor 继续向下；要看更上方可显式 startRow=0。历史一律来自普通屏幕，结果同时给出 buffer=normal 和 activeBuffer，防止误认成当前 Vim 画面。

浏览器提供“查看历史”对话框，和 Agent 使用相同 canonical 普通历史源。可以在 Vim/top 运行时查看，不退出程序、不获取输入权。页面不无限拼接旧页，内容变化时会清掉过期页面并提示重新读取。

## 变化基线与多 Agent

基线按任务身份和 Session 独立保存。A 读过不影响 B；新 Agent 第一次只看当前受限画面。最多保存 64 个最近任务基线，淘汰后下次返回新的受限快照，而不会无界增长。

基线只包含行哈希、几何和模式版本、已观察位置，不保存旧行正文。普通屏幕用稳定行位置辅助比较，减少滚动导致旧行整屏重复；备用屏幕比较行位置上的当前内容，覆盖、删除、擦除均是状态变化。没有文字变化时 lines 为空，光标等小量元数据仍可返回。

默认记录的是“这次观察到的当前状态”，不宣称所有被截断文字都已读过。一次变化超过预算时，只返回最近的受限片段，omittedChangedLines、truncated 和 nextCursor 提示未返回部分。下次默认读取不自动排空旧变化，以免积压将上下文灌满；旧内容仍保留时可显式分页或请求历史。

read_screen 会更新该任务的当前画面基线，read_history 不消费或移动当前画面的变化基线。Agent 上下文被压缩或丢失时，应显式 read_output(resync=true) 或 read_screen，不假设旧基线仍在模型上下文中。

## 返回内容的含义

mode 可为 terminal_snapshot、terminal_delta、terminal_history。lines 中每项有 line、text、offset、totalChars：完整项表示替换该行；空字符串可以表示清除该行。超长行分段时 offset 是 UTF-16 偏移，不能把片段误当完整替换，续读后按位置组合；不会切断代理对。viewportStart/viewportEnd、cols/rows 和 cursorX/cursorY 说明当前画面范围和光标位置，滚出视口的旧行不能继续当作当前屏幕。

reset=true 时丢弃对旧画面布局的假设，但受预算限制仍可能不是完整屏幕。清空、切屏、尺寸变化、显式 resync 或无法继续跟踪滚动时会重同步。不要把这些输出无条件追加成文本日志，否则会重新引入已经被覆盖的内容。

sequence/after 只辅助等待数据变化，不表示准确命令完成，也不控制无界读取。原有 after 不再触发整份历史返回。等待超时不释放锁、不重发输入。

## 分页有效性与私密

游标是带签名的定位信息，不携带正文，绑定 Session、读取者、类型和当前内容指纹。不可用于其他 Agent、用户页面、会话或读取类型。清空、覆盖、淘汰及其他内容变化使旧游标失效，应从最新页重新读取，不能返回先前缓存页。

备用屏幕仅发生自身重绘而普通屏幕内容未变时，普通历史仍可分页。若普通输出持续变化，旧页可能频繁失效；调用方应优先读当前画面，等内容稳定再按需查历史，不能无界重试。

Agent 每次读取前后仍检查私密和关联；用户历史查看不受 Agent 私密限制。私密切换会清除变化基线。关闭的保留页签仍可按原权限只读访问；删除页签后会话和游标都不可再用。任何清空都无法撤回已经进入模型上下文或被用户另存的内容。

## 消息也受预算约束

自动附带最多最近两条且正文合计不超过 2000 字符；专用读取默认 5 条/4000 字符，从最近向前分页。读取不等于确认，确认后停止重复附带但保留历史。细节见 [消息协议](messaging.md)。

## 升级

这是有意的工具返回结构变更：read_output 不再返回 chunks，read_screen 不再返回整份 text，正文仅存在于 lines。客户端必须刷新 MCP 工具目录并按新结构处理。浏览器完整恢复快照和内部单元验证可以读取 canonical 缓冲区，但不能作为绕过 MCP 预算的工具入口。加载需重启本地服务，会断开活动 SSH，必须先取得用户授权。
